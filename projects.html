PROJECT // 01 · FLAGSHIP RESEARCH Active Research

Brain MRI Surface Registration & Anatomical Alignment

Deep learning framework for non-rigid 3D cortical surface mesh alignment from raw T1 MRI scans.

Supporting research at the Xu Lab (CMU). The model aligns predicted 3D cortical meshes directly against ground-truth anatomical targets derived from raw volumetric MRI scans while preserving spatial geometry and sulcal topology. Crucially, the repository ships a fully preprocessed IXI benchmark subject run through FreeSurfer's multi-hour recon-all pipeline end to end — allowing researchers to immediately inspect and benchmark reconstructed surfaces without incurring heavy local preprocessing costs.

Technical Approach & Artifact: FreeSurfer recon-all Pipeline ➔ Cortical Surface Extraction (.mgz / .obj) ➔ Deep Surface Registration Network ➔ Freeview Mesh Validation ➔ Fully preprocessed IXI benchmark distribution

PROJECT // 02 Benchmarked

MedOptm: Compact Vision-Language Reasoning for Clinical VQA

Sub-2B parameter vision-language model pairing CvT-24 and a 1.7B LLaMA backbone for resource-efficient clinical reasoning.

High computational demands prevent standard VLMs from operating on edge clinical workstations. MedOptm introduces an architectural Token Packer that aggressively compresses convolutional vision transformer features before language projection, enabling rapid question answering over biomedical imaging data with minimal VRAM requirements.

Model Pipeline: CvT-24 Vision Encoder ➔ Token Packer (Spatial Dimension Reduction) ➔ Multimodal Projector ➔ LLaMA 1.7B ➔ METEOR 0.33 Score

PROJECT // 03 Architecture

CvT-24 Architecture Implementation (First Principles)

Ground-up implementation of the Convolutional Vision Transformer architecture written in pure PyTorch.

Features custom depthwise separable convolutional token projections, multi-stage hierarchical feature maps, and multi-head self-attention blocks without external high-level library abstractions. Developed to directly study inductive bias injection in vision transformers and serves as the visual encoder for MedOptm.

Architectural Components: Input Image [H×W×C] ➔ Depthwise Separable Conv Projections ➔ Overlapping Patch Embedding ➔ Multi-Head Self-Attention ➔ Hierarchical Stages

PROJECT // 04 Production System

Fashion Multimodal Semantic Retrieval

Fine-grained cross-modal search engine solving relational attribute collapse in frozen text encoders.

Standard vision-language models often produce near-identical embeddings for attribute-swapped prompts (e.g. collapsing "blue shirt, black pants" into "black shirt, blue pants"). By inserting a residual adapter onto the frozen vision-language embedding space and indexing with FAISS, the system achieves sub-millisecond query latency with accurate relational garment disambiguation.

Disambiguation Pipeline: Text Prompt ➔ Frozen FashionCLIP Text Encoder ➔ Trained Residual Adapter ➔ FAISS Vector Search ➔ Relational Ranking
FashionCLIP Residual Adapter FAISS Vector Search Contrastive Learning

PROJECT // 05 Deployed Web Tool

BrainScan AI: Multi-Class MRI Diagnostic Interface

Interactive clinical diagnostic web interface powered by the two-stage transfer learning model accepted at ICMLDE 2025.

A web-deployed CNN for multi-class brain tumor classification (glioma, meningioma, pituitary, no tumor). Built on a two-stage training strategy (specialized classification head extraction followed by unfreezing and fine-tuning on a modified VGG16 backbone) achieving 97.88% test accuracy.
