Surface RegistrationFreeview FreeSurfer recon-allCMU

Brain MRI Surface Registration

The repo behind the Xu Lab work — aligning predicted brain meshes against ground-truth targets from raw MRI, working directly with .mgz / .obj surface data in Freeview, dry run completed and iterating. The repo also ships one fully preprocessed IXI sample — run through FreeSurfer's recon-all pipeline end to end — so anyone exploring surface registration can inspect a real preprocessed directory directly, without running the multi-hour recon-all job themselves. That's not something readily available anywhere else public — most public IXI mirrors ship only the raw scans, not the reconstructed surfaces.

FashionCLIPResidual AdapterFAISS

Fashion Multimodal Retrieval

A natural-language image search engine for fashion — type "a red tie and a white shirt in a formal setting" and it retrieves matching images by visual and semantic similarity. A residual adapter on frozen FashionCLIP fixes a real weakness in its text encoder: near-identical embeddings for "blue shirt, black pants" vs. "black shirt, blue pants."
