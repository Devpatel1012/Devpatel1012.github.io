PROJECT // 01 · CASE STUDY Active Research

Brain MRI Surface Registration & Anatomical Alignment

Deep learning framework for non-rigid 3D cortical surface mesh alignment from raw T1 MRI scans.

Supporting research at the Xu Lab (CMU). Directly aligns predicted 3D cortical meshes against target surfaces while preserving spatial geometry and sulcal topology. Crucially, the repository ships a fully preprocessed IXI benchmark subject run through FreeSurfer's multi-hour recon-all pipeline end-to-end, enabling immediate mesh inspection in Freeview.

PROJECT // 02 · CASE STUDY Benchmarked

MedOptm: Compact Vision-Language Reasoning for Clinical VQA

Sub-2B parameter vision-language model pairing CvT-24 and a 1.7B LLaMA backbone for resource-efficient clinical reasoning.

Introduces an architectural Token Packer that compresses visual feature tokens by 75% before language projection, enabling rapid question answering over biomedical imaging data with minimal VRAM requirements.

PROJECT // 03 · CASE STUDY Architecture

CvT-24: Convolutional Vision Transformer from First Principles

Ground-up implementation of Microsoft's CvT-24 architecture written in pure PyTorch.

Features custom depthwise separable convolutional token projections, multi-stage hierarchical feature maps, and multi-head self-attention blocks without external high-level library abstractions. Injects local inductive bias and eliminates explicit positional encodings.

Code: Dedicated GitHub Repo Weights: Checkpoints in Repo Specs: 20.0M Params, 4.5 GFLOPs Compute: 1× RTX 3080 GPU
Scientific Limitation Depthwise convolutions introduce kernel memory overhead that slightly reduces peak theoretical tensor-core throughput relative to standard ViT.
First-Principles PyTorch Implementation · Zero Library Wrappers

PROJECT // 04 · CASE STUDY Retrieval System

Fashion Multimodal Semantic Retrieval

Fine-grained cross-modal search engine mitigating relational attribute binding collapse in frozen dual-encoders.

Trains a residual projection adapter on frozen FashionCLIP embeddings using hard negative contrastive pairs (where garment attributes and colors are systematically permuted), indexed with FAISS for sub-millisecond query latency.

Code: GitHub Repository Index: FAISS IVFFlat Vector Index Data: Fashion200k + Hard Negatives Latency: 0.78 ms per query
Scientific Limitation Hard negative training pairs were synthetically generated and can introduce stylistic bias toward garment adjectives; vocabulary bounded by FashionCLIP tokenizer.
Relational Attribute Disambiguation · Sub-0.8ms Query

PROJECT // 05 · CASE STUDY Deployed Web Tool

BrainScan AI: Multi-Class MRI Diagnostic Interface

Interactive clinical diagnostic web interface powered by the two-stage transfer learning model accepted at ICMLDE 2025.

A web-deployed CNN for multi-class brain tumor classification (glioma, meningioma, pituitary, no tumor) built on a two-stage training strategy (specialized classification head extraction followed by unfreezing and fine-tuning on a modified VGG16 backbone) achieving 97.88% test accuracy.

Code: GitHub Repository Paper: ICMLDE 2025 Accepted Accuracy: 97.88% Multi-Class Accuracy Stack: PyTorch & Streamlit
Scientific Limitation Evaluated on 2D axial MRI slices; multi-center prospective validation across divergent clinical scanning protocols is required prior to real clinical deployment.
97.88% Accuracy · Accepted at ICMLDE 2025

PROJECT // 06 Automation System

Autonomous Research Article Generation Pipeline

End-to-end agentic workflow orchestrating literature synthesis, technical drafting, editorial review, and automated publishing.

Constructed with the Gemini API, n8n workflow automation, Notion databases, and Dev.to webhooks. Manages multi-agent validation loops to ensure claims cite peer-reviewed literature before cross-posting.

Stack: Gemini API, n8n, Notion API Deployment: Cloud Webhooks Output: Verified Technical Articles
