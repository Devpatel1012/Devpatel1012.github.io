BUILD // 01 Architecture

CvT-24: Convolutional Vision Transformer (First Principles)

Implemented Microsoft's CvT-24 architecture completely from scratch in pure PyTorch with custom depthwise separable convolutional token projections.

Eliminates reliance on high-level library abstractions to study inductive bias injection directly. Injects local spatial structure into multi-head self-attention without explicit positional encodings.

Code: Dedicated GitHub Repo Weights: PyTorch state_dict Compute: 1× RTX 3080 GPU
Scientific Limitation Custom depthwise projection modules introduce kernel memory overhead that slightly limits peak theoretical tensor-core throughput relative to standard ViT.
Zero Library Wrappers · 20.0M Parameters Full Case Study → Dedicated Repo ↗
BUILD // 02 Retrieval System

Fashion Multimodal Semantic Retrieval

Fine-grained cross-modal search engine mitigating relational attribute binding collapse in frozen dual-encoders.

Trains a residual projection adapter on frozen FashionCLIP embeddings using hard negative attribute permutations, indexed with FAISS for sub-millisecond query latency.

Code: GitHub Repository Index: FAISS IVFFlat Index Latency: 0.78 ms per query
Scientific Limitation Hard negative training pairs were synthetically generated and can introduce stylistic bias toward garment adjectives; vocabulary bounded by FashionCLIP tokenizer.
