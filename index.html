BUILD // 01 Architecture

CvT-24: Convolutional Vision Transformer (First Principles)

Implemented the CvT-24 vision encoder entirely from scratch in PyTorch with custom depthwise separable convolutional token projections.

Eliminates reliance on high-level library abstractions to study hierarchical feature map representations and multi-head self-attention mechanics directly. Serves as the primary visual backbone for the MedOptm medical reasoning pipeline.

BUILD // 02 Retrieval System

Fashion Multimodal Semantic Retrieval

Fine-grained cross-modal search engine solving relational attribute collapse in frozen text encoders.

Standard vision-language models frequently confuse attribute order (e.g. collapsing "blue shirt, black pants" into "black shirt, blue pants"). By training a residual adapter on frozen FashionCLIP embeddings and indexing with FAISS, the system achieves sub-millisecond query latency with accurate relational garment disambiguation.

§ 03 — PHILOSOPHY
How I Think About Building

How I Think About Building

Core principles derived from hands-on research and engineering under real constraints.

PRINCIPLE // 01

Tackle the problem that might not work

I would rather pursue an ambitious hypothesis that carries a genuine risk of failure than iterate on a trivial, guaranteed increment. If a project does not feel slightly too big, it is usually not worth building.

PRINCIPLE // 02

First principles before high-level wrappers

Building a vision transformer means writing custom patch token projections and self-attention layers from scratch before importing libraries. True intuition comes from handling raw tensors, gradients, and mesh coordinates directly.

PRINCIPLE // 03

Efficiency as a primary design constraint

Anyone can train a model given unbounded compute. The real engineering discipline lies in designing compact models — like a 1.7B VLM or optimized residual adapters — that run on consumer silicon without sacrificing fidelity.
