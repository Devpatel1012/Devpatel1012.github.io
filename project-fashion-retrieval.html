RESEARCH CASE STUDY // MULTIMODAL SEMANTIC RETRIEVAL

Fashion Multimodal Semantic Retrieval

A fine-grained cross-modal search engine solving relational attribute collapse in frozen dual-encoders via residual adapter fine-tuning and FAISS vector indexing.

Code: GitHub Repository ↗ Index: FAISS IVFFlat Vector Index Data: Fashion200k + Hard Negatives Adapter: Contrastive Residual Adapter

§ 1. Problem Formulation

Pre-trained contrastive vision-language models (e.g., CLIP) encode images and text into a shared latent space. However, their text encoders suffer from relational attribute binding failure — treating 'blue shirt with black collar' and 'black shirt with blue collar' as near-identical embedding vectors because token aggregation acts primarily as a bag-of-words.

§ 2. Motivation & Hypothesis

Production cross-modal search requires fine-grained attribute fidelity at millisecond query latencies. Full end-to-end fine-tuning of vision-language foundation models is computationally prohibitive and risks catastrophic forgetting. We hypothesized that training a lightweight residual adapter with hard negative contrastive pairs (where garment attributes and colors are systematically permuted) would restore relational sensitivity without degrading general retrieval recall.

§ 3. Method & Relational Disambiguation Pipeline

The system freezes the base FashionCLIP dual-encoder and attaches a 2-layer residual MLP adapter to the text projection head. During training, hard negative triplets force the adapter to separate permuted attribute combinations.

Search Architecture Flow: Natural Language Query ➔ Frozen FashionCLIP Text Encoder ➔ Trained Residual Adapter ➔ Relational Embedding ➔ FAISS IVFFlat Vector Search ➔ Top-K Garment Candidates (<0.8 ms)

§ 4. Experimental Setup

Dataset: Evaluated on the Fashion200k benchmark augmented with synthetic attribute-swapped negative candidate pairs across garments, textures, and color adjectives.

Hardware & Framework: PyTorch, Hugging Face Transformers, FAISS-GPU on 1× NVIDIA T4 GPU (16GB VRAM).

Hyperparameters: Residual adapter: 2-layer MLP (hidden dim 512, GELU activations, dropout 0.1), AdamW optimizer, lr = 1e-4, batch size = 64, temperature = 0.07.

§ 7. Scientific Limitations & Threats to Validity

Scientific Limitations 1. Synthetic Negative Bias: Hard negatives were generated via heuristic grammar templates, which can introduce distributional artifacts not present in human search queries.
2. Domain Specificity: The adapter was trained on fashion imagery; applying this directly to general scenes or medical scans requires domain-specific contrastive re-tuning.

Future Work: Applying relational projection adapters to radiology report retrieval to separate bilateral organ qualifiers (e.g., 'right lung nodule vs. left lung nodule').
