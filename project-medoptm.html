RESEARCH CASE STUDY // CLINICAL VISION-LANGUAGE MODEL

MedOptm: Compact Vision-Language Reasoning for Clinical VQA

A resource-efficient clinical vision-language model coupling a Convolutional Vision Transformer with an architectural Token Packer and a 1.7B-parameter LLaMA backbone, achieving 0.33 METEOR on clinical question answering benchmarks under a sub-2B parameter budget.

Code: GitHub Repository ↗ Weights: PyTorch Checkpoints ([TODO: Upload to Hugging Face]) Data: ROCO & MedQuAD (120k pairs) Compute: 1× NVIDIA RTX 4090 (24GB VRAM) for 36 hrs

§ 1. Problem Formulation

State-of-the-art vision-language models (e.g., LLaVA-13B, Med-PaLM) require 16GB–80GB of high-bandwidth VRAM for multi-turn inference, creating an insurmountable compute bottleneck for edge clinical diagnostic workstations in community hospitals. When processing high-resolution biomedical images (X-ray, MRI, histopathology), standard patch tokenizers generate hundreds of visual tokens per slice, saturating cross-attention memory bandwidth and causing out-of-memory (OOM) failures during fine-tuning on consumer silicon.

§ 2. Motivation & Hypothesis

Medical imaging contains substantial spatial redundancy: large contiguous regions correspond to healthy tissue or background, while critical pathologies (e.g., micro-calcifications, focal lesions) occupy localized clusters of pixels. We hypothesized that introducing a convolutional inductive bias in early tokenization followed by an architectural Token Packer module would compress spatial visual tokens by 75% while preserving high-frequency anomaly boundaries, allowing a sub-2B parameter language model to achieve diagnostic reasoning competitive with larger foundation models.

§ 3. Method & Architectural Design

The MedOptm pipeline consists of three core components: a Convolutional Vision Transformer (CvT-24) encoder, a spatial Token Packer, and an autoregressive 1.7B LLaMA language model.

MedOptm Forward Pass: Medical Image [3×224×224] ➔ CvT-24 (Conv Projections) ➔ Token Packer (Spatial Compression: 256 ➔ 64 tokens) ➔ Linear Projection ➔ LLaMA 1.7B ➔ Autoregressive Clinical Response

CvT-24 Encoder: Uses depthwise separable convolutions for token projection across 3 stages, eliminating rigid patch boundaries and explicit positional encodings.

Token Packer: Groups adjacent visual tokens into spatially aggregated feature maps through a learned non-linear bottleneck, reducing token sequence length from 256 to 64 tokens without discarding low-frequency context.

Multimodal Projection & Language Backbone: Projects the 64 compressed visual tokens into the 2048-dimensional embedding space of a fine-tuned 1.7B LLaMA model.

§ 4. Experimental Setup

Dataset: Curated 120,000 biomedical image-caption and visual question answering pairs sourced from the ROCO (Radiology Objects in COntext) dataset and MedQuAD, preprocessed and filtered for clinical question-answer alignment.

Hardware & Compute: A single standalone workstation equipped with 1× NVIDIA RTX 4090 GPU (24GB VRAM), utilizing PyTorch 2.2 with native FlashAttention-2 and mixed-precision FP16 training.

Hyperparameters: Trained using AdamW (lr = 2e-5 with cosine learning rate scheduling), effective batch size of 32 via gradient accumulation (micro-batch size 8, accumulation steps 4), weight decay = 0.05, trained across 5 full epochs.

§ 5. Results & Baseline Comparisons

MedOptm achieved a 0.33 METEOR score on clinical visual question answering hold-out splits, demonstrating competitive performance against models with over 4× its parameter count while reducing VRAM consumption by more than 50%.

§ 7. Scientific Limitations & Threats to Validity

Identified Limitations 1. Dataset Bias: Training and evaluation relied predominantly on English-language radiology captions; the model is not evaluated on multilingual hospital records.
2. 2D Slice Constraint: The current architecture processes single 2D axial/coronal slices rather than complete 3D volumetric context, risking false negatives on lesions that span adjacent slices.
3. Hallucination Risk: In rare cases involving atypical pathologies underrepresented in ROCO, the model generates fluent but factually speculative anatomical rationales.

Future Work: Incorporating 3D volumetric patch embeddings directly from NIfTI volumes, scaling training to 3D brain tumors, and conducting blinded clinician utility evaluations.
