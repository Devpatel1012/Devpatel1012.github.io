RESEARCH CASE STUDY // CLINICAL VISION-LANGUAGE MODEL

MedOptm: Compact Vision-Language Reasoning for Clinical VQA

A resource-efficient clinical vision-language model coupling a Convolutional Vision Transformer with an architectural Token Packer and a 1.7B-parameter LLaMA backbone, achieving 0.33 METEOR on clinical question answering benchmarks under a sub-2B parameter budget. Conducted with Advisor Prof. Raj Hakani at Gujarat Technological University.

Code: GitHub Repository ↗ Backbone: CvT-24 + 1.7B LLaMA Compression: Token Packer (256 → 64 tokens) Evaluation: 0.33 METEOR Score

§ 1. Problem Formulation

State-of-the-art vision-language models require substantial VRAM for multi-turn inference, creating compute bottlenecks for edge clinical diagnostic workstations. When processing biomedical images, standard patch tokenizers generate large numbers of visual tokens, saturating attention bandwidth and increasing memory requirements during fine-tuning on consumer hardware.

§ 2. Motivation & Hypothesis

Medical imaging contains substantial spatial correlation across localized anatomical regions. We investigated introducing a convolutional inductive bias in early tokenization followed by an architectural Token Packer module to compress spatial visual tokens by 75% (reducing token length from 256 to 64 tokens), enabling a compact sub-2B parameter language model to perform clinical question answering within constrained compute budgets.

§ 3. Method & Architectural Design

The MedOptm pipeline couples three core stages: a Convolutional Vision Transformer (CvT-24) vision encoder, an architectural Token Packer, and an autoregressive 1.7B LLaMA language model.

MedOptm Forward Pass: Medical Image [3×224×224] ➔ CvT-24 (Conv Projections) ➔ Token Packer (Spatial Compression: 256 ➔ 64 tokens) ➔ Linear Projection ➔ LLaMA 1.7B ➔ Clinical Diagnosis & Explanations

CvT-24 Encoder: Employs convolutional token projections across hierarchical stages to incorporate shift, scale, and distortion invariance into early visual features.

Token Packer: Spatially aggregates adjacent visual tokens via a learned bottleneck, compressing the sequence length by 75% (from 256 down to 64 tokens) before cross-modal projection.

Multimodal Projection & Language Backbone: Projects the 64 compressed visual tokens directly into the embedding dimension of the 1.7B LLaMA language model.

§ 4. Experimental Setup

Task & Benchmarks: Evaluated on clinical visual question answering tasks requiring localized pathology identification and diagnostic reasoning.

Implementation: Built in PyTorch, structured for efficient training and inference under consumer GPU constraints.

Objective: End-to-end autoregressive language modeling conditioned on compressed visual tokens.

§ 5. Results & Baseline Comparisons

MedOptm achieved a 0.33 METEOR score on clinical visual question answering benchmarks, pairing a CvT-24 encoder with a 1.7B LLaMA backbone and 75% token compression.

Baseline comparisons are being finalized.

§ 7. Scientific Limitations & Threats to Validity

Identified Limitations 1. 2D Slice Scope: The current model operates primarily on 2D slices rather than full 3D volumetric context, relying on localized slice sampling.
2. Language & Modality Scope: Evaluated primarily on English-language biomedical question answering pairs.

Future Work: Exploring 3D volumetric token aggregation directly from NIfTI volumes, scaling to multi-modal clinical contexts, and validating across prospective clinical datasets.
